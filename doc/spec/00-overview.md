# ТЗ: shmobj — dict/list/скаляры в общей памяти для Python 3.11+ (ядро на Rust)

`shmobj` (рабочее название) хранит дерево из `dict`, `list` и простых типов в одном
сегменте общей памяти в компактном бинарном формате. Любой процесс подключается к
сегменту по имени и читает данные через прокси-объекты, без десериализации и без
копии данных в своём адресном пространстве.

**Версия 1 — только чтение (RO).** Структура собирается один раз и дальше не меняется.
Изменяемая версия (RW) будет отдельным типом структур. Её место в формате и API
зарезервировано (см. [05-rw-groundwork.md](05-rw-groundwork.md)).

## Приоритет источников

1. `03-format.md` — нормативный документ по формату.
2. `reference/shmobj_ref.py` — исполняемая трактовка формата. Если она расходится
   с `03-format.md`, это дефект: исправить нужно оба, а решение записать в `03-format.md`.
3. `python/shmobj/__init__.pyi` — контракт публичного API.
   Если он расходится с `02-api.md`, это тоже дефект.

Эталон покрывает формат, сборку, чтение, `get_many`, `iter_values`, `iter_items`,
`materialize` и `validate`. Жизненный цикл `Segment`, `repr`, отказ `pickle` и
представления `keys/values/items` в нём не реализованы: для них нормативен `02-api.md`.

## Термины

- **Сегмент** — непрерывный буфер с данными формата: `SharedMemory`, mmap файла или `bytes`.
- **Слот** — 64-битное значение: тег и встроенное значение или смещение узла.
- **Узел** — данные по смещению внутри сегмента (строка, число, список, словарь, таблица ключей).
- **Таблица ключей (KEYTABLE)** — общий для нескольких словарей список ключей с индексом.
- **Прокси** — Python-объект (`FrozenDict`, `FrozenList`), который хранит ссылку на
  сегмент и смещение и читает данные по запросу.
- **Материализация** — построение обычных `dict`/`list` из прокси.

## Быстрая проверка эталона

```bash
pip install xxhash hypothesis pytest
pytest reference/
python3 golden/gen_golden.py   # перегенерирует golden/*.bin
```

На тестовом наборе (10 000 записей вида
`{"id", "name", "score", "tags": [...], "ok", "x": None}`)
формат занимает **1.57 МБ** против 3.81 МБ у Python-объектов (41%), и эта одна копия
общая для всех процессов.
